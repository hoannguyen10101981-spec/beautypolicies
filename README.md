# Beauty Brand Policy Data

This is the **2026-09-16 snapshot** of BeautyDeals' 63-row beauty returns and free-shipping comparison for US direct-site shopping. It reproduces the seven fields published in the source table without adding brands, fields, estimates, or independent policy research. Each row preserves the table's own `reviewed_on` value and the official-source links already attached to that row.

Source comparison: https://lxlex.com/beauty-returns-free-shipping-comparison

## Files and fields

`policies.csv` and `policies.json` contain the same 63 records and these seven fields: `brand`, `return_window`, `return_postage`, `free_shipping_threshold`, `opened_products`, `official_sources`, and `reviewed_on`.

`Unconfirmed` is preserved exactly from the source table. It means the reviewed material did not establish a clear answer, or conflicting official terms remained unresolved; it is not a promise that a benefit never exists.

## Snapshot and reuse

This package corresponds to the comparison page reviewed on **2026-09-16**. Row-level review dates remain as displayed in that page rather than being rewritten to the snapshot date. Historical 48-row releases remain separate, immutable snapshots.
